Web Crypto requiere un contexto seguro. Si el navegador no lo permite al abrir un archivo local, abre este HTML mediante localhost o HTTPS. Las pruebas de IndexedDB necesitan un entorno con IndexedDB habilitado; no se afirma que una prueba en memoria demuestre persistencia física.
