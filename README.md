# Kobalt Research

Repositorio público de investigación y mecanismos técnicos de Kobalt.

## Regla de publicación

Este repositorio contiene únicamente material que haya sido autorizado explícitamente para publicación pública.

## Principio

> Claridad conceptual antes que código.

Los mecanismos publicados aquí se documentan con su formulación conceptual, especificación matemática, implementación de referencia y demos reproducibles.
