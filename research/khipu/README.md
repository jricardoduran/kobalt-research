# Khipu mechanisms

- K4: [W][L][B][H] — cuerpo opaco autodelimitado y verificable.
- K5: [T][W][L][B][H] — cuerpo nativo tipado autodelimitado y verificable.
- K5.1: primer perfil implementado, T16 + W8 + LEN bit-level + BODY byte-aligned + SHA-256.

Las implementaciones JS y PHP de K5.1 comparten vectores byte a byte.
